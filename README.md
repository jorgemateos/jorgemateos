# Jorge Mateos

**Administrador de sistemas y técnico IT**

Me dedico a la administración de sistemas Windows y Linux y al soporte técnico. Me gusta automatizar las tareas repetitivas: aquí guardo los scripts que uso para configurar servidores, montar entornos de Active Directory y desplegar servicios con Docker.

### Áreas de trabajo

- **Windows Server y Active Directory**: puesta en marcha de servidores, dominios, unidades organizativas, grupos y permisos.
- **Linux**: configuración de servidores Ubuntu y securización del acceso SSH.
- **Contenedores**: instalación y gestión de Docker y Docker Compose.
- **Soporte IT**: redes, equipos de usuario y resolución de incidencias.
- **Automatización**: scripts en PowerShell y Bash.
